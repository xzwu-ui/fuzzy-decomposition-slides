02

FREEDOM AT THE BOUNDARY

H(α) 可以自由选择什么？

为什么课件排除 λ = 0 或 λ = 1？

所有索引 α 都属于 [0, 1]。当 λ = 0 时，没有 α < 0；当 λ = 1 时，没有 α > 1，因此相应索引族为空。

若采用集合论约定 ∩∅ = X、∪∅ = ∅，两式可以延伸到这些端点，因为 A0 = X、A1+ = ∅。这里保留课件的原始范围；端点限制并非等式失效的反例。

H(α) 必须等于某一种截集吗？

不必。严格高于 α 的元素必须包含，严格低于 α 的元素必须排除；恰好等于 α 的元素可以分别选择。因此当有多个临界元素时，H(α) 可以是位于两种截集之间的其他集合。

动画里算出相同结果，就已经证明了吗？

有限采样只能提供直观。对有限论域，可以为每个需要排除或找回的元素构造中点见证，用有限组阈值精确验证。对一般论域的结论，则由第 04 节的四个包含方向证明保证。
