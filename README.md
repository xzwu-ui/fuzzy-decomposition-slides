## 直接运行

1. 解压 ZIP，保留目录结构。
2. 双击 `index.html`，用 Chrome、Edge、Firefox 等现代浏览器打开。
3. 按 F 进入全屏；若浏览器拒绝全屏 API，使用浏览器的 F11。
4. 按 T 开始7分钟排练计时，N 查看本页讲稿。

所有脚本、公式库和中文字体均在本地。没有 CDN、远程请求、安装依赖或构建要求，支持 `file://` 直接离线打开。请先解压，不要在 ZIP 内直接双击。

另提供同样功能的单文件 `standalone.html`，将字体、KaTeX、样式和脚本全部内嵌，复制这个文件到另一台电脑即可运行；编辑时推荐多文件项目。

## 交互内容

- 第2页：滑块和直接拖动 SVG 均能连续改变阈值；阈值线、交点、投影区间、开闭边界和公式同步计算。支持 ≥ / > 切换、循环播放、暂停与重置。教学曲线为 `μ(x)=1−|x−2|/2`，论域 `[0,4]`。当 λ=1，普通截集是 `{2}`，强截集为空；图中重合的闭端点代表同一个点。
- 第3页：构造四元素实例 `μ=(0.90,0.60,0.60,0.20)`。在临界 α 高度对元素单独勾选，不允许改变非临界成员。每次重算普通截集、强截集与 H。默认只在0.60层选择 q，使 H 既不等于普通截集也不等于强截集。这不是课件例3.1。
- 第4、5页：5个阈值逐个计算 H 并执行交／并运算。标尺明确以空心 λ 标出未取的端点。播放有连续移动的 α 指针，可暂停、单步、拖动进度、重播和重置。最后一步自动生成有限论域的中点见证证书。
- 第6页：按空格依次出现四个包含方向和最后结论，当前证明高亮。使用中点明确构造所需 α，不依赖有限动画。
- 第7页：课件六元素的真实数据与动态集合高亮。左／右逼近按钮播放真实计算，“显示交集／显示并集”按钮使用临界隶属度的中点证书精确计算。可勾选 c 是否进入 H(0.76)，两式结果保持不变。
- 第8页：成镜像的左右逼近箭头及交／并恢复公式；最后一句逐步出现。

## 数学约定与准确性

`A_λ={x:μ_A(x)≥λ}`，`A_λ⁺={x:μ_A(x)>λ}`。记号 `+` 表示强截集，统一替代课件中的强截集排版记号。所有索引 α 都属于 `[0,1]`。

本项目保留课件条件：普通恢复式 `λ≠0`，强恢复式 `λ≠1`。相应端点会产生空索引族；若采用集合论约定 `∩∅=X`、`∪∅=∅`，恢复等式可延伸到端点，因为 `A_0=X`、`A_1⁺=∅`。端点限制不是等式失效的反例。

有限采样仅用于演示，不能作为一般无限运算的证明。有限论域精确证书的依据是：左式对每个 `μ(x)<λ` 的元素取 `α=(μ(x)+λ)/2`，保证其被某个 H 排除；所有 `μ(x)≥λ` 的元素在每个下方 H 都必定存在。右式对每个 `μ(x)>λ` 的元素取 `α=(λ+μ(x))/2`，保证其被某个 H 包含；其余元素在所有上方 H 都必定排除。因而这组有限见证阈值可以代表有限论域上的无限交／并结果。一般论域的证明在第6页。

计算层用千分单位的整数存储教学数据与滑块阈值，精确比较 `>`、`≥`、`=`；中点可用精确的半整数表示。没有使用误差容忍比较来扩张边界。界面滑块的最小增量是0.001，这只是交互分辨率，不改变定理对连续参数的陈述。

## 编辑与部署

内容：编辑 `index.html`。数学数据和默认临界成员：编辑 `js/fuzzy-set.js`。动画采样顺序：编辑 `js/theorem-animation.js`。布局配色：编辑 `css/style.css`。讲稿面板数据在 `js/speaker-notes.js`，应与 Markdown 讲稿同步修改。

无需服务器。也可在此目录运行 `python3 -m http.server 8000`，访问 `http://localhost:8000`；或将整个目录上传到静态托管。服务器上的版本也不需要外部公式或字体服务。修改多文件项目后，运行 `python3 tools/build-standalone.py` 重新生成 standalone.html，使单文件版同步。

基础数学测试：`node tests/math-tests.cjs`。浏览器测试需要外部开发依赖 Playwright 和其 Chromium，不属于演示运行依赖。

排练计时不是自动翻页：按既定25、45、60、75、75、75、45、20秒分配，共420秒。讲稿操作提示说明哪些动画应暂停、何时推进。实际语速和临场提问会影响用时，请至少排练一遍。
